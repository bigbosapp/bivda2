Buka BIVDA melalui server lokal

Browser membatasi file JavaScript yang dipisah jika index.html dibuka langsung dari folder.

  1. Jalankan start-app.cmd di folder BIVDA.
  2. Biarkan jendela server terbuka.
  3. Buka http://localhost:5173 di browser.

Untuk perangkat lain, aplikasi harus diterbitkan melalui Firebase Hosting. Lihat README.md.
